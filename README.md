# Switch Lab

Tu panel de control para Windows, desde Android o iPad.

## Descargar

[Descargar la ultima version para Windows](https://github.com/robleflow/switch-lab-releases/releases/latest/download/SwitchLab-Windows-x64.zip)

Extrae la carpeta completa y abre **SwitchLab.exe**. No requiere Python ni VS Code.

- Android: APK incluido; conexion por Wi-Fi o USB.
- iPad/iPhone: Safari por Wi-Fi, vincular con el codigo de la PC y Compartir > Agregar a pantalla de inicio.
- Actualizar: Ajustes > Buscar actualizaciones, desde el navegador de la PC. Conserva perfiles y conexiones.
- Cada PC guarda sus datos localmente. Windows debe permanecer encendido y ejecutando Switch Lab.
- Versiones antiguas sin actualizador: descarga esta version una vez para habilitarlo.

[Ver versiones](https://github.com/robleflow/switch-lab-releases/releases/latest)
